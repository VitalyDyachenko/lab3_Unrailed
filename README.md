# Unrailed
Это подобие популярной игры в Steam с тем же названием. Здесь нужно не дать поезду сойти с рельс, добывая ресурсы (дерево и камень), и загружить их в крафт-вагон, чтобы делать рельсы.

## Управление
E - взять

Q - положить

стрелки - ходить

P - пауза

O - выход

M - двигать поезд
